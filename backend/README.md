# Vestir backend

NestJS API for Vestir. See [../ROADMAP.md](../ROADMAP.md) for the app spec, architecture, and phase plan.

## Setup

```bash
npm install
npm run start:dev
```

Server runs on `http://localhost:3000` by default.

## Tests

```bash
npm test          # unit tests
npm run test:e2e  # e2e tests
```
